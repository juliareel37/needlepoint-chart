# Design System Page

This folder contains the internal standardized component route at `/design-system`.

## Purpose
- House normalized, reusable component standards derived from existing app patterns.
- Keep standards separate from the audit inventory in `/design-audit`.
- Provide a safe place to iterate on component specs before replacing production usage.

## Current Scope
- Foundations (tokens, spacing, radius)
- Primitives (buttons, icon buttons, form controls, toggles)
- Navigation and status patterns (tabs, toolbar controls, badges, banners)
- Composite components (palette popover shell, modal shell, toast/decision banner)

## Notes
- This page does not automatically refactor production components.
- Standard components shown here are based on recurring patterns found in the existing UI.
